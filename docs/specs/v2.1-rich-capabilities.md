## 1. Scope & Locked Decisions

Following `v2.0.0`, Lite Gemini `v2.1` brings four rich capabilities into the 120Hz native Liquid Glass interface while explicitly keeping History Management, Gems/`@` Connectors, and a custom composer microphone button out of scope:

1. **Native LaTeX Math Typesetting & 120Hz Code Syntax Highlighting**
   - Typeset `$...$` inline math and `$$...$$` display math natively via CoreText + OpenType `MATH` fonts (`SwiftMath`), with automatic fallback to monospaced LaTeX while an expression is mid-stream (`!isClosed`) or contains unsupported macros.
   - Render fenced code blocks in `CodeBlockCardView` (and inside the Canvas Code tab) with async off-main-actor syntax highlighting (`HighlightSwift` over system `JavaScriptCore`), `90ms` streaming debounce, `(language, colorScheme, contentHash)` LRU caching, and zero layout shift.
2. **Native Code Folder Upload (`文件夹原生上传`)**
   - Dropping a directory onto `AdaptiveComposerView` or selecting **"Upload Code Folder…"** from the `+` attachment menu stages the folder natively instead of punting to Classic Web Mode.
   - `FolderAttachmentScanner` walks the directory off-main-actor, pruning `.git`, `node_modules`, `.build`, `DerivedData`, `.next`, `dist`, `target`, `__pycache__`, `.venv`, `.DS_Store`, and oversized binary blobs so real-world repositories never trip Gemini's file-count quota (`StatusCode 1036`).
   - `GeminiActionDriver` injects the filtered relative-path files (`webkitRelativePath`) into Gemini's `<code-folder-uploader>` (`input[type="file"][webkitdirectory]`), with `WKUIDelegate.runOpenPanelWith` folder URL handoff as secondary fallback.
3. **Native Canvas Split Pane (`[ Preview | Code ]` & Markdown Reader) + Quick Mode Handoff**
   - Decode full `_.Cu` (`Artifact`) payloads (title, raw Markdown/code/HTML `text`, `language`, `artifactType`) from `StreamGenerate` and `batchexecute` (`hNvQHb`), backed up by DOM extraction from `<immersive-panel>`.
   - Expand a right-hand Liquid Glass **Canvas Split Pane** in Main Window (`>= 740pt` side-by-side split; `< 740pt` full-content sheet overlay so `360×400` stays unclipped):
     - **Code / HTML / SVG Canvas:** `[ Preview | Code ]` segmented toggle — `Preview` renders HTML/CSS/JS/SVG inside a strictly sandboxed `WKWebView` (`WKWebsiteDataStore.nonPersistent()`, external network navigation blocked); `Code` renders syntax-highlighted source with Copy and Save File.
     - **Document / Markdown Canvas:** `[ Reader | Markdown ]` toggle rendering native Markdown, tables, math equations, and syntax-highlighted code with Copy and `.md` export.
   - **Quick Mode (`⌥Space`) Locked Decision:** Quick Mode remains compact (`548pt`); clicking a Canvas or Deep Research report card in Quick Mode hands the session off to Main Window and opens the Split Pane there.
4. **Native Deep Research End-to-End Flow (`深度研究`)**
   - Expose **Canvas** and **Deep Research** tool toggles in the `+` composer menu (syncing with Gemini's `toolbox-drawer` and displaying a removable Liquid Glass tool pill in the composer).
   - **Stage 1 — Research Plan Confirmation Card:** Decode `deep-research-confirmation-widget` (`attachmentType 19` / DOM `[data-test-id="plan-step"]` + `[data-test-id="time-estimation-message"]`) into a native Liquid Glass card with **`Start Research`** (clicks `[data-test-id="confirm-button"]`) and **`Edit Plan`** actions.
   - **Stage 2 & 3 — Live Progress & Native Report Reader:** Stream live `deep-research-processing-status` updates during multi-site search, and open the completed Deep Research report (`_.Cu` `artifactType 4`) directly inside the native Split Pane Reader.

## 2. Verified Live Gemini Protocol & DOM Contract (`2026-11-26`)

Verified against `boq_gemini-web-uiserver` (`gemini.google.com/app`):

- **`_.Cu` (`Artifact` Protobuf / JSPB in `Candidate` field `31` `[30]` & `42` `[41]`):**
  - `field 1` (`[0]`): `artifactId` (`String`)
  - `field 3` (`[2]`): `title` (`String`)
  - `field 4` (`[3]`): `asyncTaskId` (`String`)
  - `field 5` (`[4]`): `text` (`String` — full Markdown or code text)
  - `field 11` (`[10]`): `type` (`Int`)
  - Submessage `field 14` (`[13]`, `artifactType = 1` Document): `field 1` = `text`, `field 5` = `language`
  - Submessage `field 15` (`[14]`, `artifactType = 2` Code/Web): `field 1` = `code`, `field 2` = `language`
  - Submessage `field 16` (`[15]`, `artifactType = 4` Deep Research Report): `field 1` = structured report, `field 2` = visual HTML report, `field 4` = grounding sources
  - Submessage `field 18` (`[17]`, `artifactType = 3` Editable Canvas): `field 1` = `text`, `field 3` = `language`
- **Deep Research Plan & Status DOM / Wire:**
  - Confirmation widget: `deep-research-confirmation-widget`, steps `[data-test-id="plan-step"]` / `.research-step-title`, estimate `[data-test-id="time-estimation-message"]`, confirm `[data-test-id="confirm-button"]`, edit `[data-test-id="edit-button"]`.
  - Processing status: `deep-research-processing-status`, `deep-research-processing-indicator`.
  - Report entry chip: `deep-research-entry-chip-content`, `[data-test-id="immersive-entry-chip-view-report-button"]`.
- **Toolbox Drawer (`Canvas` & `Deep Research` Composer Modes):**
  - Host: `input-area-v2 toolbox-drawer`, items `toolbox-drawer-item button.toolbox-drawer-item-button` / `.toolbox-drawer-item-list-button[role="menuitemcheckbox"]`, active deselect `.toolbox-drawer-item-deselect-button`.
- **Code Folder Upload (`<code-folder-uploader>`):**
  - Trigger menu: `uploadMenuTrigger` → `code-import button` → `[data-test-id="upload-code-folder-list-item"]` / `[data-test-id="hidden-local-code-folder-upload-button"]` / `input[type="file"][webkitdirectory]`.
  - Reconstructs folder hierarchy via `File.prototype.webkitRelativePath.split("/")`.
