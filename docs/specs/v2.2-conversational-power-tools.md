# Spec: Lite Gemini v2.2 — Conversational Power Tools & Native Micro-Interactions

- **Status:** Implemented (`7 / 7` tickets completed — Wave 1A/1B/1C & Wave 2 end-to-end integration verified)
- **Target release:** `v2.2.0`
- **Depends on:** `docs/specs/v2-native-ui.md` (`v2.0.0`), `docs/specs/v2.1-rich-capabilities.md` (`v2.1.0`)
- **Deferred items outside Category 1:** `docs/specs/backlog-future-capabilities.md`

## 1. Scope & Product Goals

Lite Gemini `v2.2` brings the full suite of **Category 1 in-conversation power tools** from Google's latest Gemini Web frontend (`boq_gemini-web-uiserver_20261125.05_p0` + `bg3/boq-bard-web/islands`) into the 120Hz native macOS Liquid Glass shell:

1. **Highlight-to-Quote Follow-Up (`划词引用追问`)** — Select any passage in an assistant response to attach up to 5 structured quote banners above the composer (or jump straight into `Btw` side-inquiry).
2. **Regenerate Variants & Conversation Branching (`重生成变体菜单与对话分支`)** — Expand the per-turn regenerate control with length/tone/model/no-tool variants, and add one-click **Branch in New Chat** from any turn (`1..N`).
3. **`Btw` Ephemeral Side-Question Panel (`Btw 旁路临时追问浮窗`)** — Ask quick clarifying questions via `/btw <question>`, `⌘⇧B`, or selection action in an isolated Liquid Glass side popover backed by read-only main-chat context, without polluting the active conversation thread; optionally summarize key takeaways (`2–5` bullets) back into the main chat.
4. **Public Share Links & Document Export (`公开分享链接与文档导出`)** — Create public `gemini.google.com/share/<id>` links (whole chat or single turn), export conversations natively to `.md` / `PDF`, and export turns to Google Docs, Gmail Drafts, Colab, or Sheets.
5. **Global `⌘K` Conversation Search & Neural Turn TTS (`全局历史搜索弹窗与单条消息自然语音朗读`)** — Hybrid instant local SQLite + cloud semantic conversation search (`⌘K`), plus single-turn neural MP3 voice playback (`AVAudioPlayer` with lookahead sentence prefetch and playback-rate control).

## 2. Permanent Architectural Constraints

All `v2.2` tickets must preserve the non-negotiable invariants established in `v2.0` and `v2.1`:

1. **Owner Focus Gate (`v2-native-ui.md` §3.4):** Automated tests, protocol probes, and screenshot harnesses must never launch `Lite Gemini.app` interactively, call `NSApp.activate`, or call `makeKeyAndOrderFront`.
2. **Zero-Warning Swift 6 Universal Gate:** `SWIFT_VERSION = 6.0`, `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor`, `CLANG_WARN_UNGUARDED_AVAILABILITY = YES_AGGRESSIVE`, `MACOSX_DEPLOYMENT_TARGET = 14.0`, Universal `arm64 + x86_64`, zero `@unchecked Sendable`, `nonisolated(unsafe)`, or `@preconcurrency`.
3. **Constant `ComposerTextView` Structural Identity:** Presenting `ComposerQuoteBannerListView`, `BtwPopoverPanelView`, or the `⌘K` search overlay must **never** alter the SwiftUI structural view path of `MainRootView.contentSlot()` → `ChatSurfaceView` → `AdaptiveComposerView` → `ComposerTextView`, preserving focus and active CJK IME marked text (`hasMarkedText()`).
4. **Dual-Path Bridge Resilience:** Every write/RPC capability must support Google's new **Omakase GraphQL HTTP Gateway** (`ExecuteGraphqlHttp`) while retaining **Angular Closure DOM / `batchexecute` fallbacks** so account-level Mendel rollout differences never break native actions.

## 4. Detailed Feature Specifications

### 4.1 Pillar 1 — Highlight-to-Quote Follow-Up (`划词引用追问`)

#### Domain & State (`ComposerModels.swift` & `ComposerDraftState.swift`)
- Add `QuotedPassage: Identifiable, Codable, Equatable, Sendable`:
  - `id: UUID`
  - `quotedText: String` (trimmed, capped at `2,000` characters matching `btwUtils` / `ComposerQuoteBannerList`)
  - `conversationId: String?`
  - `turnId: String?` (`requestId` / `responseId` pair)
- Extend `ComposerDraftState`:
  - `var quotes: [QuotedPassage] = []` (hard cap: `maxStagedQuotes = 5`).
  - `func addQuote(_ passage: QuotedPassage) -> Bool` — deduplicates identical `(turnId, quotedText)` or allows up to 5 entries; sets `isQuoteCapAlertVisible = true` when attempting to add a 6th quote.
  - `func removeQuote(id: UUID)` + single-step undo buffer (`lastRemovedQuote`) for 5-second restore.
  - Extend `hasTopExtras` in `AdaptiveComposerView` to include `!draft.quotes.isEmpty` so the composer automatically morphs from idle `.clear` glass to `.regular` glass whenever quotes are staged.

#### Selection Capture UX (Main Window & Quick Mode)
- **Primary Gesture — Selection Floating Action Pill & Context Menu:**
  - Introduce a lightweight selection observer (`ResponseTextSelectionMonitor`) scoped to assistant turn content in `ConversationTimelineView`:
    - **Keyboard Shortcut:** `⌘⇧'` (**Quote in Reply** / `引用追问`) and `⌘⇧B` (**Ask in Btw** / `旁路追问`). Captures selected text from the current responder via a non-destructive pasteboard snapshot-and-restore helper (`NSPasteboard` changeCount guard) when selection originates inside a `SwiftUI.Text` run, or directly when inside a `SelectableMarkdownView` / code block.
    - **Floating Selection Pill (Main Window):** On mouse-up (`NSEvent.addLocalMonitorForEvents(matching: .leftMouseUp)`) inside an assistant message when a non-empty text selection exists, anchor a compact non-activating Liquid Glass toolbar pill `8pt` below the selection rect with two buttons:
      1. **`Quote` (`arrowshape.turn.up.left`, `"引用追问"`)** — stages `QuotedPassage` into `draft.quotes` and focuses `ComposerTextView`.
      2. **`Btw` (`bubble.left.and.bubble.right`, `"旁路追问 ⌘⇧B"`)** — opens `BtwPopoverPanelView` pre-seeded with `QuotedPassage` (Main Window directly; Quick Mode hands off or opens inline compact `Btw` mode).

#### Composer Quote Banner UI (`ComposerQuoteBannerListView.swift`)
- Placed inside `AdaptiveComposerView`'s top extras stack (above `ComposerTextView`, alongside `AttachmentTileStrip` and `activeToolModeChip`):
  - Displays `reply` icon + muted up-to-3-line preview (`lineLimit(3)`) + dismiss `×` button.
  - When `quotes.count > 2` and collapsed, displays the first 2 quotes with an inline `+N more` (`+N 条引用`) expand toggle on row 2; when expanded, displays all quotes (`<= 5`) with `Show less` (`收起`).

#### Bridge Write-Path Serialization
- When `draft.quotes` is non-empty on `sendPrompt`:
  - **GraphQL / WebChannel path:** Populate `highlightToAskContext.quotedContexts` (`[{ quotedText, requestId, conversationId }]`).
  - **DOM Quill write-path (universal compatibility):** Format staged quotes into structured Markdown blockquotes prepended cleanly above the user's prompt (`> ...\n\n<prompt>`) while preserving `userDisplayText` + `quotedPassages` on the local `ChatTurn` model so `ChatTurnRowView` renders the user's quoted chips above their message bubble (matching `d_` in `ChatTranscript`).

### 4.2 Pillar 2 — Regenerate Variants & Conversation Branching (`重生成变体与对话分支`)

#### Regenerate Variants (`RegenerateVariant`)
- Define `RegenerateVariant: String, CaseIterable, Codable, Sendable`:
  - `.tryAgain` (`1001` — `"Try again"` / `"重新生成"`)
  - `.shorter` (`1005` — `"Shorter"` / `"更精简"`)
  - `.longer` (`1004` — `"Longer"` / `"更详细"`)
  - `.simpler` (`"Simpler"` / `"更通俗"`)
  - `.casual` (`"More casual"` / `"更口语化"`)
  - `.professional` (`"More professional"` / `"更正式"`)
  - `.retryWithoutTools` (`"Retry without tools"` / `"不使用工具重试"`, shown when the turn invoked Canvas / Deep Research / extensions)
- **UI in `ChatTurnRowView` (Latest Turn):**
  - Left-clicking the `↻` orb immediately runs `.tryAgain` (zero extra clicks for the common path).
  - Clicking the adjacent chevron capsule (`↻ ▾`) or secondary-clicking `↻` opens a compact Liquid Glass menu with the variants above plus **"Switch model & retry"** (`切换模型重试` → sub-list of `session.availableModels`).
- **Bridge Execution (`GeminiActionDriver.regenerateLatestResponse(variant:modelId:)`):**
  - Primary: Opens Gemini's `modify-response-button` / `regenerate-button` menu in the hidden WebView and clicks the matching option (`data-test-id` / `1004` / `1005` / `retry-without-tool-button`), or switches model first when `modelId` is specified.
  - Fallback (when a tone modifier menu item isn't exposed by the current model): Submits an edit/follow-up turn directive cleanly only with explicit user action, never silently mutating history.

#### Conversation Branching (`Branch in New Chat` / `从此处分支`)
- **UI in `ChatTurnRowView` (All Completed Turns `1..N`, not just latest):**
  - Add an `arrow.triangle.branch` action orb in the assistant turn action bar (`help: "Branch in new chat"` / `"从此处创建分支对话"`).
- **Bridge Execution (`GeminiActionDriver.branchConversation(conversationId:requestId:responseId:)`):**
  - **Path A (Omakase GraphQL):** Execute `ChatResponseActionBarBranchMutation` with `{ conversationId, requestId, responseId }` → receives new `c_...` `conversationId`.
  - **Path B (DOM Fallback):** Locate the matching `<model-response>` turn in the hidden WebView, click `[data-test-id="branch-button"]` (inside `message-actions` / overflow menu), and observe SPA URL transition to `/app/<newConversationId>`.
- **Post-Branch State Transition:**
  - Seed local `ConversationCacheStore` with turns `1..branchIndex` under `newConversationId` for **0ms instant visual continuity**, navigate the session to `newConversationId`, refresh `recentConversations`, and show a subtle status toast (`"Branched into a new chat"` / `"已从此处创建分支对话"`).

### 4.3 Pillar 3 — `Btw` Ephemeral Side-Question Panel (`Btw 旁路临时追问面板`)

#### Trigger Entry Points
1. **Slash Command in Composer:** Typing `/btw ` or submitting `/btw <question>` (matching `/^\/btw(?:\s+([\s\S]*))?$/iu`) intercepts submission before hitting the main thread, clears `/btw` from the main composer, and opens `BtwPopoverPanelView` (immediately sending `<question>` if non-empty).
2. **Selection Pill / Shortcut:** Selecting text + clicking `Btw` or pressing `⌘⇧B` opens `BtwPopoverPanelView` with the selected `QuotedPassage` attached.
3. **Top-Right Chat Action / Shortcut:** Pressing `⌘⇧B` with no selection toggles `BtwPopoverPanelView` anchored to the trailing side of the chat surface.

#### Official Context Packing Algorithm (Ported 1:1 from `btwUtils-CRYhVwyt.js`)
- Constants:
  - `maxRecentTurns = 10`
  - `maxBackgroundChars = 16_000`
  - `maxFocusedTurnResponseChars = 8_000` (`16_000 / 2`)
  - `maxRegularTurnResponseChars = 2_400`
  - `maxQuoteChars = 2_000`
- First-turn prompt assembly (`BtwPromptBuilder.buildFirstTurnPayload`):
  1. Extract up to the last `10` completed turns from `ChatSessionStore.turns` (always including the turn matching `quote.turnId` if older than the last 10).
  2. Format each turn as:
     ```text
     [Turn K | r_...]
     User: <prompt>
     Gemini: <response truncated to 8000 (focused) or 2400 (other)>
     ```
     working backwards from newest turn until `16,000` characters is reached.
  3. Prepend `Main conversation background (read-only):\n<packedTurns>`.
  4. Append any `quotes` as `Highlighted passage (from turn <id>):\n"""\n<quotedText>\n"""`.
  5. Append system instruction:
     - With quote: `"You are answering a side question in Btw (an ephemeral side panel) so the main conversation stays clean. Focus on the highlighted passage, using the main conversation only as background. Keep your answer concise—under ~150 words unless asked for detail."`
     - Without quote: `"You are answering a side question in Btw (an ephemeral side panel) so the main conversation stays clean. Use the main conversation only as background context. Keep your answer concise—under ~150 words unless asked for detail."`
  6. Append `Question: <cleanUserQuestion>` (while displaying only `<cleanUserQuestion>` in `BtwPopoverPanelView`'s bubble!).
- Subsequent turns within the same `Btw` thread send `<cleanUserQuestion>` directly in that ephemeral session.

#### Isolated Ephemeral Transport (`BtwSessionEngine`)
- **Critical Isolation Requirement:** Opening or streaming in `Btw` must **never** navigate or mutate the primary `GeminiSessionEngine`'s active `/app/<id>` DOM or interrupt an in-flight main chat stream.
- **Implementation:** `BtwSessionStore` lazily instantiates a lightweight secondary headless `GeminiSessionEngine` sharing the active account's `WKWebsiteDataStore` (cookies/auth), locked to **Temporary Chat (`isTemporaryChat = true`)** with `autoOpenNativeArtifacts = false`. When `Btw` is cleared or closed (after idle timeout), the ephemeral session resets cleanly with zero server-side history footprint.

#### "Send to Main Chat" (`汇总回填主对话`)
- Clicking **"Send to main chat"** (`发送到主对话`) inside `BtwPopoverPanelView`:
  1. Sends the official summarization prompt in the `Btw` ephemeral session (`"Summarize the key takeaways, clarifications, or decisions from this Btw side thread in 2 to 5 concise Markdown bullet points (- ...) so they can be added back to the main conversation. Output only the bullet points with no preamble or closing text."`).
  2. Formats the result as:
     ```markdown
     Notes from Btw:
     - ...
     ```
  3. Appends it into the main `ComposerDraftState.text` and focuses `ComposerTextView` so the user can review or immediately press `↩` to send.

#### UI Geometry
- **Main Window:** Floating Liquid Glass card (`width: 360pt`, `maxHeight: 460pt`, `.regular` glass surface with `.clear` header controls: `Btw` title, `Clear`, `Send to main chat`, `×`) anchored at bottom-trailing above the composer (`padding(.trailing, 18)`), draggable/dismissible via `⎋`.
- **Quick Mode (`⌥Space`):** If triggered in Quick Mode, renders as a compact inline collapsible drawer above the composer or hands off to Main Window on expand.

### 4.4 Pillar 4 — Public Share Links & Document Export (`公开分享链接与文档导出`)

#### Public Share Link (`ShareSheetPopoverView`)
- **Entry Points:**
  - Conversation-level: Add a Share/Export button (`square.and.arrow.up`) in `MainTopBarView`'s trailing Liquid Glass cluster (or conversation actions menu) when `!turns.isEmpty && !isTemporaryChat`.
  - Turn-level: Add `square.and.arrow.up` to `ChatTurnRowView`'s action bar (offering `"Share this response…"` + `"Share entire chat…"` + export options).
- **Execution (`GeminiActionDriver.createPublicShareLink(scope:)`):**
  - Calls `useCreatePublicShareLinkMutation` (`id: "2/eOGb8QHyoSUHf18EjPRYa7b0FcKTQZawXJzi8i8+JeA="`).
  - Handles transient error code `1218` (`SHARE_ERROR_TARGET_NOT_PERSISTED` right after streaming finishes) with an automatic `2,000ms` single retry, matching `useCreatePublicShareLinkMutation-BmjRHGN_.js`.
  - Copies the resulting `https://gemini.google.com/share/<id>` URL to `NSPasteboard.general` and displays a native confirmation pill with **"Copy Link"** and **"Open in Browser"**.

#### Local & Cloud Export
1. **Native Markdown Export (`.md`):** Zero-network instant export of either a single turn or the full conversation (`# <Title>\n\n**User:** ...\n\n**Gemini:** ...`) via `NSSavePanel`.
2. **Native PDF Export (`.pdf`):** Renders conversation turns (including `SwiftMath` vector/high-DPI equations and syntax-highlighted code blocks) into a clean paginated A4/Letter printable HTML/attributed document and writes PDF bytes directly via `WKWebView.createPDF(configuration:)` + `NSSavePanel` (no browser print dialog hijack).
3. **Google Cloud Export (`Google Docs` / `Gmail Draft` / `Colab`):**
   - Calls `useExportMessageMutation` (`id: "2/5VQOYy/e314m5sPqgdiBi2I/yACWnQk4VqP+bTgFhX8="`) with `EXPORT_SERVICE_DOCS`, `EXPORT_SERVICE_GMAIL`, or `EXPORT_SERVICE_COLAB` (shown when turn contains Python code).
   - Validates returned `artifactUrl` (`https://docs.google.com/...`, `https://mail.google.com/...`, `https://colab.research.google.com/...`) and opens it via `NSWorkspace.shared.open(url)`.

### 4.5 Pillar 5 — Global `⌘K` Search Modal & Neural Turn TTS (`全局搜索与自然语音朗读`)

#### Global `⌘K` Hybrid Conversation Search (`ConversationSearchModalView.swift`)
- **Shortcut & Menu:** Register `⌘K` (and a magnifying-glass search row at the top of the `Recent ▾` popover) to open a centered Liquid Glass command-palette search modal (`width: 560pt`, `maxHeight: 420pt`).
- **Two-Tier Hybrid Search Engine (`ConversationSearchCoordinator`):**
  1. **Tier 1 — 0ms Local SQLite Search:** Add an FTS5 / indexed `LIKE` query on `ConversationCacheStore` searching cached conversation titles and turn Markdown bodies for the active `accountKey`, returning instant results on every keystroke.
  2. **Tier 2 — 200ms Debounced Cloud Semantic Search:** Query `SearchChatsPageQuery` (`id: "2/LLcwgETnZDeKTolcftrhEUT4oNNrjiKwmznSgDTfiNw="`, `pageSize: 20`) to retrieve server-side semantic + full-history matches across older uncached conversations (`historySnippets`), deduplicating by `conversationId` while preserving snippet highlights.
- **Keyboard UX:** `↑` / `↓` moves selection, `↩` loads the selected conversation (`workspace.activeSession.selectConversation(id:)`) and dismisses the modal, `⎋` closes without losing composer focus.

#### Single-Turn Neural Cloud TTS (`TurnSpeechController.swift`)
- **Spoken Text Sanitizer & UTF-8 Sentence Chunker (Ported 1:1 from `ChatTranscript-CxjY4yNA.js` `ad()` / `Of()`):**
  1. Strip fenced code blocks (` ```[\s\S]*?``` `), display math (`$$[\s\S]*?$$`), Markdown table alignment rows (`|---|---|`), image syntax, link URLs (keeping anchor text), raw `https://` URLs, heading `#` markers, and inline formatting tokens (`*`, `_`, `~`, `` ` ``).
  2. Detect locale from turn metadata (`CandidateField.language` / CJK character ratio → `zh-CN`, `en-US`, `ja-JP`, etc.).
  3. Split into chunks of **`<= 3,000` UTF-8 bytes** aligned on sentence boundaries (`。`, `！`, `？`, `.`, `!`, `?`, `\n`), falling back to clause punctuation (`，`, `；`, `,`, `;`) if a single sentence exceeds 3,000 bytes.
- **Lookahead MP3 Streaming & Native `AVAudioPlayer`:**
  - `TurnSpeechController` (`@MainActor @Observable`, singleton per workspace so starting TTS on turn B automatically stops turn A):
    - Requests chunk `0` via `useResponseTtsQuery` (`appId: "TTS_APP_ID_BARD"`, `audioEncoding: "TTS_ENCODING_MP3"`), decodes `base64url` → `Data`, and starts `AVAudioPlayer(data:)` (`enableRate = true`).
    - Immediately prefetches chunk `i + 1` in the background while chunk `i` is playing so multi-paragraph responses play gaplessly.
    - Fallback: If `useResponseTtsQuery` fails (e.g., unsupported locale or offline), gracefully falls back to hidden DOM `<tts-control-v2>` click or `AVSpeechSynthesizer`.
- **UI in `ChatTurnRowView`:**
  - Speaker orb (`speaker.wave.2`) in the assistant turn action bar.
  - While active on that turn, morphs into a compact Liquid Glass playback pill (`[ ⏸  1.0× ▾  ⏹ ]`) supporting `1.0×`, `1.25×`, `1.5×`, and `2.0×` playback speeds.
